# MEMORY

> AirClaw 的跨会话长期记忆。本文件由 Agent 按「记忆协议」维护，也可由用户在右侧 Inspector 中直接编辑。
>
> 写入规则见 `workspace/AGENTS.md` 的记忆协议一节。要点：
> - 只记录跨会话仍然有效的稳定事实与约定
> - 不记录临时任务细节、一次性查询结果、可从知识库检索到的事实
> - **严禁写入任何敏感内容**
> - 条目必须写成 `### YYYY-MM-DD 主题` 三级标题，不要用无序列表（列表项无法被去重校验识别）
> - 条目按日期倒序或正序均可，但同一主题只保留一条，更新而非追加重复项
